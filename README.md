# Student Manage App

초등학생의 출석, 칭찬, 발표, 과제 수행 여부를 관리할 수 있는  
Android 기반 학생 관리 애플리케이션입니다.

Spring Boot 서버와 연동하여 학생 데이터를 관리할 수 있도록 구현했습니다.

## 프로젝트 기간

- Android App 개발: 2025.10 ~ 2026.02
- 개인 프로젝트

## 기술 스택

- Kotlin
- Android
- Retrofit
- Room DB
- Git
- Gradle

## 주요 기능

| 기능 | 설명 |
|---|---|
| 학생 관리 | 학생 등록, 조회, 수정, 삭제 |
| 출석 관리 | 출석 체크 및 월별 조회 |
| 칭찬 관리 | 칭찬 점수 부여 및 조회 |
| 발표 관리 | 발표 점수 부여 및 조회 |
| 과제 관리 | 과제 수행 여부 및 평가 조회 |
| 활동 관리 | 활동 수행 여부 및 평가 조회 |

## 앱 구조

- Android App
- ViewModel
- Repository
- Room DB
- Retrofit API 연동

## 서버 연동

Spring Boot 서버 API를 호출하여 학생 데이터를 송수신했습니다.  
앱과 서버 간 JSON 데이터 형식을 맞추기 위해 DTO 구조를 정리했습니다.
